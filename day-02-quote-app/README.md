# Day 2: Quote App

A small app that shows a random quote and its author.
Click **New Quote** to get another one.

## What I Used
- HTML
- Tailwind CSS
- JavaScript (Fetch API)
- API: https://dummyjson.com/quotes/random

## Features
- Shows one quote and its author
- "New Quote" button gets a new quote
- "Loading..." message while waiting
- Error message if the fetch fails
- Button is disabled while loading

## What I Learned
- How `fetch` asks an API for data
- `async` / `await` and `try / catch / finally`
- Connecting a button with `addEventListener`
- Disabling a button with `newQuoteBtn.disabled`

## How to Run
Open `index.html` in your browser.
