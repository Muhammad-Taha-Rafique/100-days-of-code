# Day 1: Posts Viewer

A small page that shows 10 posts from an API.

## What I Used
- HTML
- Tailwind CSS
- JavaScript (Fetch API)
- API: https://jsonplaceholder.typicode.com/posts

## Features
- Shows 10 posts as Tailwind cards
- "Loading..." message while waiting
- Red error message if the fetch fails

## What I Learned
- How `fetch` gets data from an API
- Turning the response into data with `.json()`
- `async` / `await` and `try / catch`
- Showing data on the page with JavaScript

## How to Run
Open `index.html` in your browser.
